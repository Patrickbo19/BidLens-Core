# Owner activation gates

There is **no current the402 provider-account owner gate** for the live INCOME 2 architecture. The older instruction in this file is retired.

Current unavoidable owner-controlled gates are only actions that genuinely require the account holder, legal acceptance, identity verification, or a provider approval step, for example:

- accepting provider/platform terms when required;
- completing identity/business verification when required;
- connecting or approving a production payout/cash-out rail when one is selected;
- supplying an approved provider credential through the platform's secure secret mechanism after the provider has actually approved INCOME 2;
- final public directory submission/approval actions when the launch gate is met.

Do not place passwords, API keys, private keys, seed phrases, recovery tokens, 2FA codes, or solver capability keys in chat, source control, or public docs.

The authoritative current state and next gates are in `INCOME2_STATE.md`.
